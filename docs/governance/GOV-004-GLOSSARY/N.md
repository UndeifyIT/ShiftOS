# Introduction

This document defines all official ShiftOS terminology beginning with the letter **N**.

These definitions are authoritative and shall be used consistently throughout the ShiftOS Product Bible, engineering documentation, architecture specifications, database design, APIs and user interfaces.

---

# Namespace

## Business Definition

A Namespace is a logical boundary used to organize related resources and prevent naming conflicts.

---

## Technical Definition

Namespaces group related functionality, files, services or identifiers under a common prefix.

---

## Business Context

Examples include:

- API namespaces
- Database schema namespaces
- Documentation namespaces
- Event namespaces

---

## Related Specifications

- API-001 Backend Architecture

---

## Related Terms

- Module
- Service
- Domain

# Navigation

## Business Definition

Navigation is the system that enables users to move between different areas of ShiftOS.

---

## Technical Definition

Navigation includes menus, sidebars, breadcrumbs, links, tabs and routing.

---

## Business Context

Navigation differs by user role.

Managers, Supervisors and Employees each receive role-specific navigation.

---

- UI-002 Navigation

- Dashboard
- Menu
- Route

# Navigation Flow

## Business Definition

A Navigation Flow is the defined sequence of screens a user follows to complete a task.

---

## Technical Definition

Navigation flows describe valid transitions between pages while respecting permissions and business rules.

# Network

## Business Definition

A Network is the communication infrastructure that allows devices and services to exchange information.

---

## Technical Definition

ShiftOS relies on secure internet connectivity between client devices, backend services and cloud infrastructure.

---

## Business Context

Temporary network interruptions should not result in data corruption or inconsistent application state.

---

# Network Latency

## Business Definition

Network Latency is the time required for data to travel between a user's device and ShiftOS services.

---

## Technical Definition

Latency directly influences application responsiveness.

## Business Context

- Login

- Live updates

## Business Definition

Normalization is the process of organizing database structures to reduce redundancy and improve consistency.

---

## Technical Definition

---

## Business Context

Normalization minimizes duplicated information and improves long-term maintainability.

# Notification

## Business Definition

A Notification is a message generated by ShiftOS to inform a user about an event requiring awareness or action.

---

## Technical Definition

Notifications are generated by backend events and delivered through supported communication channels.

---

## Business Context

Examples include:

- Shift assigned
- Shift updated
- Shift cancelled
- Attendance reminder
- Task assigned
- Task overdue
- Announcement published
- Invitation received

# Non-Goal

## Business Definition

A Non-Goal is a capability that ShiftOS intentionally chooses not to include within a defined scope.

---

## Technical Definition

Non-Goals prevent scope creep and provide clarity regarding product boundaries.

---

## Business Context

- Payroll processing
- Leave management
- WhatsApp integration
- Native mobile applications
- AI workforce optimization
- Open shift marketplace
